Enable browser account management

For a new local-account installation

Use the installer's explicit account-management option. It creates the initial administrator inside the dedicated private account directory.

./install --auth local --enable-account-management

After installation, the first administrator signs in and opens People to add a teammate.

For an existing installation

  1. Stop the application and all account-admin commands. Back up accounts and configuration.
  2. Use the documented account relocation command to move the same account file into its dedicated owner-only directory and retain a verified recovery copy.
  3. Enable the local-account Compose overlay and update the canonical account-file configuration as described in the installation playbook.
  4. Restart the application, sign in, and verify account changes plus another person's matter access with synthetic users.

Keep all other secrets read-only. Do not expose a writable secrets directory to make the form work.
