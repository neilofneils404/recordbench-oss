# Your first synthetic matter

These two tiny UTF-8 text records are invented for a first CPU alpha or
contributor-preview journey. They contain no real case material or hidden
attachments. Download both `.txt` files to the computer running your browser.

1. Create a matter named **Lantern practice**.
2. Open **Sources**, select both `.txt` files, review the selection and upload.
3. Wait until both sources are ready. Search for **lantern** using word search.
   Both records should appear. Open each result and read its original.
4. Add a case note: **The delivery note counts three batteries; the later
   inspection counts two. The records do not explain the difference.**
5. Open **Work product → Export matter bundle** to download the complete bundle.
   Open the ZIP and the exported case notes; verify the saved note is present.

This proves a small manual review workflow. No AI model, generated answer,
OCR, media processing or throughput claim is part of the exercise.
Keep the matter open until you have checked your downloaded work.
