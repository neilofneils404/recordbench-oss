# Teaser media rights

`recordbench-teaser.mp4` is the maintainer-approved RecordBench teaser. It shows
synthetic demonstration material and includes an original soundtrack supplied
by the maintainer for this video.

The soundtrack is excluded from the repository's Apache-2.0 software license.
Its inclusion does not grant a standalone music license. Permission for other
uses of the music must be obtained from the maintainer. The original audio file
is intentionally not distributed separately in this repository.

`recordbench-teaser-preview.jpg` is a still extracted from the approved video.
See [the branding guide](../BRANDING.md) for presentation guidance.
